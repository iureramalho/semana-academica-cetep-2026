# II Semana Acadêmica do Curso Técnico em Informática

Site do evento do CETEP de Medeiros Neto, Bahia.

**Tema:** Conectados ao Futuro: Tecnologia, Inteligência Artificial e Novas Oportunidades.

[Acessar o site](https://iureramalho.github.io/semana-academica-cetep-2026/)

## Estrutura

- `index.html`: conteúdo editorial e metadados.
- `content.js`: programação, oficinas, convidados, patrocinadores e configuração da Even3.
- `styles.css`: identidade visual e layout responsivo.
- `app.js`: navegação e apresentação do conteúdo.
- `assets/`: imagens do evento otimizadas para a web.

Site estático, sem instalação ou compilação. O GitHub Pages publica a raiz da branch `main`. A data e a programação permanecem identificadas como previstas até validação final da organização.
